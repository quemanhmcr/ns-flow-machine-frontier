# 02 — Fixed Cartan Tensor + Diagonal Heat

Let \(Ce_I=\lambda_Ie_I\) be a fixed orthonormal curl eigenbasis and write

\[
u=\sum_Iz_Ie_I.
\]

The ad-invariant Cartan 3-form determines a fixed totally alternating tensor

\[
f_{IJK}=\Omega(e_I,e_J,e_K).
\]

Then the Euler amplitudes obey

\[
\boxed{
\dot z_I^{NL}
=-\frac12\sum_{J,K}
(\lambda_K-\lambda_J)
 f_{IJK}z_Jz_K.
}
\]

Viscosity contributes only

\[
\boxed{-\nu\lambda_I^2z_I.}
\]

So the full modal grammar is

\[
\boxed{
\text{fixed reversible Cartan law}
+
\text{diagonal irreversible heat}.
}
\]

Nothing in the interaction rules is rebuilt dynamically. The state only changes the amplitudes being contracted against the same tensor.
